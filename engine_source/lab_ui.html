Lexical analysis · finite automata

A lexer is a deterministic finite automaton. Type some code and press Play: the automaton reads one character at a time, follows an edge, and — using maximal munch — remembers the last accepting state so it can backtrack when it runs into a dead end.

Register allocation · graph colouring

Two variables that are alive at the same time interfere and cannot share a register. Allocation = colouring the interference graph with K colours (Chaitin–Briggs): simplify (remove nodes with fewer than K neighbours), possibly mark a spill candidate, then select colours while popping the stack. Change K and watch spills appear.
